# Мозг

**Автор проекта: Кушалиев Амир** · [Telegram: @foidslayer1038](https://t.me/foidslayer1038)

Личный помощник с несколькими AI-провайдерами, голосовым вводом и форматированием ответов.

**Стек:** Node.js · JavaScript · HTML · CSS.

## Запуск

Дважды нажми START.cmd. Откроется http://127.0.0.1:4318. На этом компьютере используется уже установленный Node.js из Codex; на другом нужен Node.js 22+ (https://nodejs.org). Ничего устанавливать через npm не нужно.

1. Нажми «Подключить API».
2. Выбери провайдера: Groq, Google Gemini, OpenRouter или DeepSeek. Ссылка «Получить ключ» ведёт в его консоль. Вставь ключ только в поле приложения.
3. Нажми «Проверить и подключить».
4. Напиши вопрос или включи микрофон. Для микрофона нужен проверенный профиль Groq, выбранный в настройках голоса. Диалог может работать через другого провайдера. Повторное нажатие остановит запись. Проверь распознанную фразу и отправь стрелкой ↑. Запись ограничена 90 секундами.
5. Кнопка ♫ включает чтение новых ответов системным голосом браузера. Если русского голоса нет, его нужно установить в системе или использовать текст.

## Несколько ключей и провайдеров

Ответы ИИ отображаются с Markdown-таблицами, заголовками, выделением, списками и блоками кода. Широкие таблицы прокручиваются горизонтально. Кнопка копирования и скачивание диалога сохраняют исходный Markdown. Парсер Marked включён локально (MIT, см. public/vendor/marked-LICENSE.md); HTML из ответа не выполняется, внешние изображения не загружаются автоматически.

В настройках нажми ＋ рядом с «Активный профиль», задай название, выбери провайдера и вставь ключ. Можно создать несколько профилей одного провайдера. Каждый профиль хранит собственный ключ, модель и результат проверки. Выбор другого профиля переключает будущие запросы; автоматического перебора ключей при ошибках или лимитах нет.

Список моделей загружается после проверки ключа. В поле «Модель» можно выбрать ID из подсказок или ввести его вручную. Проверка подключения подтверждает ключ и загрузку каталога; доступ к конкретной модели подтверждается первым запросом к ней. У OpenRouter каталог публичный, поэтому ключ отдельно проверяется через /key.

Для Groq используй Free Plan, для OpenRouter ищи модели с суффиксом :free; у Gemini бесплатность зависит от модели и аккаунта. DeepSeek может требовать оплаченный баланс. Приложение не управляет оплатой и не обещает бесплатность всех моделей. Настройки API не создают ключи у провайдера.

Адреса API фиксированы для каждого провайдера: Groq — api.groq.com/openai/v1, Gemini — generativelanguage.googleapis.com/v1beta/openai, OpenRouter — openrouter.ai/api/v1, DeepSeek — api.deepseek.com/v1. Ключ отправляется только выбранному провайдеру, HTTP-перенаправления отключены.

## Анализ статистики

На главном экране есть «Посмотреть пример @natgeo»: реальный аккаунт National Geographic используется только как узнаваемый ориентир. Все показатели, сюжеты публикаций и выводы в примере вымышлены. «Показать учебный разбор» работает без API и входа. Для своих вопросов по примеру нужен ключ ИИ; отметка о вымышленных данных включается и в контекст модели.

Чтобы загрузить свой файл: нажми ＋ слева от поля сообщения или «Загрузить статистику» в левом меню, выбери файл, дождись его имени над полем и нажми «Что у меня залетело?». Для ответа нужен подключённый ИИ-профиль. CSV-шаблон можно скачать кнопкой под быстрыми действиями. Замени учебные строки своими; указывай просмотры, лайки, комментарии, сохранения и репосты обычными числами. XLSX сначала сохрани как CSV.

Для прямого подключения нажми Instagram в верхней панели. Интеграция требует разовой настройки приложения Meta владельцем: см. INSTAGRAM-SETUP.md. До настройки прямой вход недоступен, загрузка файлов продолжает работать. После подключения доступна выборка до 12 последних публикаций; сводка отправляется ИИ только по явному выбору пользователя.

Загрузи CSV, TSV, JSON или TXT до 2 МБ. XLSX и изображения пока не поддерживаются. Для CSV автоматически считаются суммы распознанных числовых колонок и три лучших публикации по просмотрам (или охвату). Сокращения вроде «12 тыс.» не учитываются в суммах — используй числа 12000. Поддерживаются кавычки, запятая, точка с запятой и табуляция, UTF-8 и Windows-1251.

Для больших файлов в модель отправляются рассчитанная сводка и начало таблицы; приложение показывает это рядом с именем файла. Для JSON/TXT отправляется только начало файла. Длинные диалоги сокращаются до последних сообщений. Для проверки загрузки есть example.csv — это вымышленные данные.

## Хранение и доступ

Профили, ключи и переписка находятся только в памяти вкладки и исчезают после обновления. Ключи не пишутся на диск, в localStorage или журнал. Сервер доступен только на этом компьютере, на 127.0.0.1. Запросы защищены токеном вкладки и проверкой адреса сервера.

При запросе сообщения и выбранные фрагменты статистики отправляются выбранному провайдеру; при распознавании запись отправляется в Groq с ключом выбранного голосового профиля. При переключении провайдера текущий диалог будет отправлен ему в следующем запросе; чтобы этого избежать, начни новый разговор. Озвучка зависит от браузера и выбранного системного голоса. Не загружай данные, которые не хочешь передавать провайдеру. Скачай диалог кнопкой перед закрытием, если хочешь его сохранить.

Прямое чтение Instagram подготовлено, но требует настроенного Meta-приложения и живой проверки. Автоматический монтаж, публикация и управление компьютером не подключены. Помощник может анализировать переданные данные и готовить идеи и сценарии. Воспроизведение голоса, качество ответов, доступность моделей и бесплатные лимиты зависят от среды и провайдера.

## Остановка

Закрытие страницы останавливает микрофон и озвучку, сервер продолжает работать до перезапуска Windows. Чтобы остановить сервер сразу, запусти STOP.ps1 через PowerShell. Повторный START.cmd открывает уже запущенный экземпляр.

## Проверка и разработка

Запуск вручную: `node server.mjs`. Альтернативный порт задаётся переменной PORT. Не задавай внешний адрес прослушивания: приложение рассчитано на личное локальное использование.

Документация: https://console.groq.com/docs/quickstart, https://ai.google.dev/gemini-api/docs/openai, https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion, https://api-docs.deepseek.com/api/list-models/. Работающие ключи нужны для проверки живых ответов; без них можно проверить интерфейс, обработку таблиц и маршрутизацию на имитированных ответах.
